## 需求

- **FILE-01** 导图以 JSON 文件保存，扩展名为 `.mindmap.json`，内容为 simple-mind-map 的完整数据（含 `smmVersion`）。
  - 验证：自动化测试，序列化再反序列化后数据相等，`smmVersion` 存在。
- **FILE-02** Cmd+O 打开本地 `.mindmap.json` 文件。Cmd+S 把修改写回原文件；尚未关联文件的新导图首次 Cmd+S 时弹出另存为。Cmd+Shift+S 另存为。
  - 验证：Chrome 中打开文件 → 修改 → Cmd+S，用编辑器查看磁盘上的文件已更新。
- **FILE-03** 有未保存的修改（尚未写入文件）时，页面标题显示未保存标记。关闭或刷新标签页不弹出确认，内容由 FILE-05 自动保存。
  - 验证：修改后检查标题出现标记；刷新页面不弹确认框，标记在恢复后仍在。
- **FILE-04** 可以导入 `.xmind` 文件（XMind 8 及 XMind 2020 以后的格式），主题的树结构和文字（含换行）完整导入，导入结果作为一个尚未保存的新导图打开。
  - 验证：导入用户提供的 K8s .xmind，普通主题数与原文件一致（content.json 中为 96 个主题，无概要 / 自由主题），抽查若干多行节点的文字。
- **FILE-05** 当前导图（内容、文件名、关联的本地文件）在每次修改后立即自动保存到浏览器的 IndexedDB（正在编辑框里输入的文字在结束编辑后保存）。再次打开页面时恢复这张导图；若它关联了本地文件，Cmd+S 仍写回该文件。恢复后，未保存标记与关闭前一致（关闭前已存进文件则无标记）。新建、打开、导入会替换浏览器里保存的导图。浏览器存储按网址隔离，不同网址各自保存。
  - 验证：编辑后不保存文件，立刻刷新页面，内容和未保存标记都还在；打开一个本地文件、修改、关闭标签页再打开，Cmd+S 后磁盘上的文件被更新；加入大图（合计 > 5MB）仍能自动保存并恢复。
- **FILE-06** Cmd+S 写回已关联的文件前，若该文件在上次打开或保存之后被其他程序修改过，先弹出确认，用户取消则不写入。
  - 验证：打开文件后，用文本编辑器改动并保存该文件，再在导图里 Cmd+S，出现确认框；取消后文件内容不变，确认后被覆盖。
