## 实现

- [x] `draftStore.ts`：IndexedDB 读 / 写当前导图（内容文本、文件名、文件句柄、文件修改时间、未保存标记），专属数据库名

- [x] 单元测试：草稿写入后读出一致、无草稿时返回空
