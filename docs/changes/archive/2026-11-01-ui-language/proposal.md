## 为什么（起因）

用户（2026-11-01）：希望界面是英语，这样别人也能用；最理想是有多语言设置。

## 意图

> ⚠️ 由 Claude 起草，请用户确认或改写。

界面提供英语和中文两种语言。第一次打开时按浏览器语言自动选择（中文浏览器显示中文，其他显示英语），顶栏可以随时切换，选择会被记住。切换只影响界面文字，不改动导图里已经写好的内容。

## 设计要点（Claude 的判断，请确认）

1. **直接做语言设置，不只是改成英语。** 界面文字只有约 40 条（顶栏按钮、格式工具栏提示、弹窗文案、默认主题名等），做成「英 / 中两份词表 + 切换」比单纯翻译多不了多少工作量。
2. **不引入 i18n 库**（如 i18next）。两种语言、几十条文字，一个带类型检查的词表文件就够了：漏翻某一条时 TypeScript 直接报错。以后要加第三种语言，只需再加一份词表。
3. **默认语言跟随浏览器**：`navigator.language` 以 `zh` 开头用中文，否则英语。你自己的浏览器如果是中文，打开仍是中文，切到英语后会记住。
4. **切换语言立即生效、不刷新页面**，导图内容不变。只有之后新建的导图、新插入的节点，默认文字才用新语言（如新节点「分支主题」→ "Topic"）。
5. **语言选择存在 localStorage**：只是一个偏好设置，几个字节，不需要 IndexedDB。
6. **项目文档仍用中文**（见 decisions.md），只改界面。

## 需求差分

### ADDED Requirements

**UI：界面语言**

- **UI-01** 界面支持英语和中文。顶栏按钮、格式工具栏的提示、缩略图按钮、所有弹窗与确认框文案、页面标题、文件选择对话框里的文件类型说明，以及新建导图的中心主题、新插入节点的默认文字，都使用当前语言。导图中已有的内容不随语言变化。
  - 验证：分别切到两种语言，逐一检查顶栏、格式工具栏（悬停提示）、缩略图按钮、保存失败 / 放弃修改 / 外部修改确认等弹窗；新建导图后中心主题与按 Tab / Enter 插入的节点文字为对应语言；打开含中文内容的导图，切换语言后内容不变。
- **UI-02** 第一次打开时，浏览器语言为中文则显示中文，否则显示英语。顶栏提供语言切换，切换后立即生效、无需刷新，选择保存在当前浏览器，下次打开沿用。
  - 验证：浏览器语言设为英语时首次打开为英语；切到中文后刷新仍为中文；切换时正在编辑的导图内容与未保存标记不变。
